OPEN AND EDIT ON WINDOWS
1. Right-click the ZIP file and choose Extract All.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose Joseph_Portfolio_Personalized.
4. Open index.html to edit text. Open style.css to adjust the design.
5. Replace the placeholder email YOUR_EMAIL@example.com in index.html with an email address you are comfortable sharing publicly. Update the mailto link too.
6. Find both “My contribution” lines in index.html and replace them with a truthful description of your own work. Do not claim work completed by another group member.
7. Add your portrait to images/profile-photo.jpg if you want a photo. The site will show a placeholder until you add it.
8. Double-click index.html to preview it in Brave or Chrome.

PROJECT SCREENSHOTS
The portfolio already includes screenshots in images/maze and images/libai. Keep these folders in place so the images continue to display. You may replace any image with a better screenshot, but keep the filename the same or update the matching src path in index.html.

PRIVACY AND ACCURACY
The LibAI profile screenshot in this portfolio has sensitive account values blurred. Review all screenshots before making the site public. Only include details you are comfortable sharing. Edit project descriptions and contribution statements to reflect the actual project and your role.

PUBLISHING
To make the website accessible online, you can publish it with GitHub Pages. Make sure you are allowed to publish all project screenshots and group-project materials before making the repository public.


PROJECT SCREENSHOT SLIDERS
